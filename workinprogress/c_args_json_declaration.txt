

- french -

déclarer dans un fichier à la syntaxe json la liste des options que le programme va accepter.

s'en servir pour afficher l'aide ( usage() ) et pour construitre les paramètres du programme.

_______________________________________________________


première utilisation : le programme json lui-même

actuellement il n'utilise pas al_options.

build/json
First argument : filename to open in read only mode to parse in json.
Second argument : filename to open in read only mode to parse in json for template.
                  template is used for json unification ie extratcing fields from a template pattern
Output : dump parsed json to standard output.
-d debug
-m non recursive
-p path
-c check only (no print)
-b bare : no indent
aljson_main version 0.1
